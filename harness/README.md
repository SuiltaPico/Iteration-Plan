# 策略迭代插件（WIP）

给 AI Harness 用的策略迭代机制：不碰 CLAUDE.md / AGENTS.md，不需要界面。
系统只记账、摆证据，留存和淘汰由 AI 或人拍板。

当前先在 DeepSeek Harness（`@deepseek-ai/dsh` 0.2.2-rc.1）上验证。

## 插件 `dsh-itp/`

一个 JSON 文件就是全部数据：`strategies`（id、标题、状态 trial/kept/eliminated、教训）和 `logs`。

| 机制 | 做法 |
|---|---|
| 注入 | `systemPrompt.context` 每轮把活着的策略、每条的账、已淘汰策略的教训交给模型 |
| 记账 | `itp_record`：模型只报这局有没有按某条策略做（used / unused） |
| 提策略 | `itp_propose`：新策略进入试用 |
| 拍板 | `itp_decide`：keep / trial / eliminate；证据少于 3 局时工具会提醒，但不拦 |
| 成绩 | 监听 `goal/changed`，goal 完成或受阻时运行 `scoreCommand` 取客观分数，模型改不了 |
| 账面 | 每条策略：用它的局平均分 vs 没用它的局平均分 |

在 profile 的 `cordis.patch.yml` 里挂载：

```yaml
- insert:
    - id: itp
      name: dsh-itp
      config:
        file: !!js process.env.ITP_FILE
        scoreCommand: !!js process.env.ITP_SCORE_CMD
```

## 实验 `bench/`

任务：模拟炒股。80 天、一只股票、起始资金 10000、手续费 0.2%。
价格由预设公式生成（趋势 × 周期正弦 + 固定种子噪声），每局参数不同。
得分 = 拿到「全知最优」收益的百分比；同时给出「第一天买入持有」作参照。

| 文件 | 作用 |
|---|---|
| `market-server.mjs` | 市场黑盒。参数从标准输入读，只暴露 status/buy/sell/next，只给当天及以前价格 |
| `market-client.mjs` | 放进模型工作区的客户端 |
| `score.mjs` | 插件用的评分命令，只读 |
| `run2.sh` | 第二轮：`GROUP=exp\|ctl SEQ=A\|B`，每组同一工作区连跑 6 局 |
| `run.sh` / `run-control.sh` | 第一轮的实验组 / 对照组 |
| `audit.sh` | 扫日志里的可疑操作 |

防作弊：模型以普通用户 `agent` 运行；市场代码、参数、分数文件在 `/root/box`（agent 读不到）；
参数不出现在进程参数里；环境变量只传代理和模型 key；账本每局快照到 agent 读不到的地方；事后审计日志。
脚本里的路径按实验机布局写死（`/opt/dsh`、`/opt/lab*`、`/root/box`）。

## 结果（进行中）

### 第一轮（旧插件：模型自评好坏）

实验组：装插件。对照组：不装插件、共用工作区、什么都不提醒。行情两组相同。

| 局 | 行情 | 有策略库 | 无策略库 |
|---|---|---|---|
| 1 | 上涨 + 周期 | 38.6% | 46.9% |
| 2 | 下跌 + 周期 | 53.9% | 41.9% |
| 3 | 短周期、大噪声 | 35.2% | 17.9% |
| 4 | 强上涨、小波动 | 29.5% | 37.8% |
| 5 | 下跌、大波动 | 42.2% | 26.0% |
| 6 | 温和上涨 + 周期 | 47.4% | 47.3% |
| 平均 | | 41.1% | 36.3% |

发现：
- 模型给策略自评几乎全是「帮上忙」，自评不可信 → 第二轮改成客观分数。
- 只用 1 局就拍板 → 第二轮加证据提醒、允许已留存策略退回。
- 对照组没有自发写笔记；第 5 局看到了自己留下的脚本但不敢读，
  因为任务里写了「不要读取实现」 → 第二轮改措辞，明确目录里其他文件可随意使用。

### 第二轮（新插件：客观分数 + 证据账面），序列 A

| 局 | 有策略库 | 无策略库 |
|---|---|---|
| 1 | 49.4% | 35.6% |
| 2 | 65.4% | 64.1% |
| 3 | 39.7% | 36.2% |
| 4 | 15.1% | 62.3% |
| 5 | 40.9% | 进行中 |
| 6 | 68.6% | 进行中 |

观察：
- 第 4 局（单边强涨）策略库里的周期波段打法拖了后腿，对照组反而大胜。
- 实验组第一次按账面淘汰了一条策略（用过 2 局平均 27.4，没用 2 局平均 57.4），并针对单边上涨提了新策略。
- 对照组第 3 局自发把交易日志存成 `trading_log.txt`，第 4 局读了它，用来判断行情形态。
  模型没写「经验总结」，但会留原始记录并回头参考。
